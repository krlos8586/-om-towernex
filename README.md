# O&M LPS/TOWERNEX

Hub de operación y mantenimiento LPS Grupo × TowerNex (Región Costa).

- **Trabajos Sitetracker**: trabajos del portal TowerNex con estado, prioridad, plantilla y ticket.
- **Sitios**: ficha por sitio con sus trabajos, enlaces a Sitetracker y al SharePoint de TowerNex, y nota propia.
- **SharePoint TWN**: índice de la biblioteca *TowerNex - Contratistas O&M / LPS* (actas de facturación, preventivos por mes, correctivos, conciliados, actas de reunión).
- **Pendientes**: lista personal (se guarda en el navegador).

El contenido está cifrado (AES-GCM, clave derivada con PBKDF2-SHA256, 600 000 iteraciones). Solo se abre con correo y contraseña autorizados.
Los datos son una copia leída con la sesión del usuario; se actualizan publicando una nueva versión.
